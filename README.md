# Akuma Max · 英语学习工具

一个完全本地运行的英语学习应用：**21,430 词词库**、间隔重复复习、四档记忆评分、**68 套真题**、写作范文、AI 教练、语法速查与水平测试。

不注册账号、不上传学习数据、不需要后端服务。

---

## 一、先选一种形态

三个版本内容完全相同，区别只在**打开方式、离线能力和语音质量**。按你的场景挑一个就行，不用都装。

| 形态 | 打开方式 | 离线 | 发音 | 适合谁 |
|---|---|---|---|---|
| **网页完整版** | 点链接，浏览器打开 | 缓存过的内容可离线 | 在线词典 + 浏览器语音 | 想在电脑或手机浏览器里直接用 |
| **单文件手机版** | 一个 `mobile.html` 文件 | **完全离线**（数据内嵌） | 同网页版 | 想把整个 App 存进手机、经常没网 |
| **安卓 APK** | 下载安装，桌面有图标 | **完全离线** | **端侧神经语音**，音质最好 | 安卓手机，想要系统级体验 |

**新手建议**：先在电脑上点[网页完整版](https://shuzhiaa.github.io/AKUMA-MAX/)试一下，觉得好用再装 APK。

> **关于 iPhone / iPad**：目前没有原生 iOS 安装包。苹果要求所有 iOS 应用必须用 Apple 开发者账号签名，免费账号 7 天就过期，上架 App Store 还要走审核——没有"免签名、不会过期"的原生安装方式。
>
> iPhone 用户请用**网页完整版或单文件手机版**：用 Safari 打开后点分享按钮 →「添加到主屏幕」，就会得到一个带图标的独立 App，**和 APK 一样是全屏无地址栏、离线可用**，只是发音走系统语音而不是端侧模型。
>
> 后续若发布 iOS 版本，会在本仓库的 Releases 里明确标注，届时此处会更新。

## 二、GitHub 小白怎么下载

### 下载安卓 APK

1. 打开 [Releases 页面](https://github.com/shuzhiaa/AKUMA-MAX/releases/latest)。
2. 找到最新版本号（例如 `v1.3.3`），展开下面的 **Assets**。
3. 点击 `AkumaMax-1.3.3-signed.apk` 下载。同名的 `.txt` 是签名与安全自检说明，可以不看。
4. 按下一节安装。

浏览器提示"文件太大 / 不安全"是 200MB 级安装包的常见误报，选"保留"即可。安装前请确认文件来自本仓库的 Releases。

### 下载单文件手机版

1. 打开 <https://shuzhiaa.github.io/AKUMA-MAX/mobile.html>。
2. 在浏览器菜单里选"添加到主屏幕"（iPhone 用 Safari 的分享按钮 → 添加到主屏幕），之后离线也能打开。
3. 也可以进仓库文件列表点 `mobile.html` → 右上角 `Raw` → 浏览器菜单"另存为"。

### 收藏与更新

- 点仓库右上角 `Star`，以后在 GitHub 个人主页能快速找到。
- 网页版：刷新页面就是最新版。
- APK：到 Releases 下载新版本覆盖安装，签名不变，学习记录会保留。

## 三、安装安卓 APK

1. 把 APK 文件复制到手机，点击安装。
2. 系统提示"禁止安装未知来源应用"时，按提示给文件管理器或浏览器一次安装权限，装完可以关掉。
3. 首次启动会导入词库与真题，约 10–20 秒，等首页出现再操作。
4. 需要约 250MB 可用存储空间。

支持 **Android 8 及以上**，安装包内含 arm64 与 x86_64 兼容库。应用不申请网络、通讯录、定位等权限。

## 四、第一次使用：三步

1. **定起点**：首页顶部有水平测试入口，做一次测试会自动推荐适合你的词书和难度区间；也可以跳过，直接到「学习」页自己选。
2. **定目标**：「设置 → 每日目标」决定每天学几个新词。
3. **开始复习**：回到「今日」页点「开始复习」。第一次用先去「学习」页学几个新词。

之后每天只需打开「今日」页按提示复习。数据存在本机浏览器或 App 内，不需要登录。

### 词书和难度在哪改

在**「学习」页底部的「词书范围」和「选词难度区间」**，不在设置页。词库里有 17 本词书（小学英语、高考英语、英语四级、四级核心词汇、英语六级、六级核心词汇、考研词汇书、考研英语、雅思、托福、英语专业四级、英语专业八级、同等学力申硕、英语等级考试、旅游英语、日常高频等），加一个"全部词书"选项。

## 五、功能导览

### 今日
- 待复习数量、今日新词进度、连续学习天数。
- 近 14 天学习曲线；没有记录时只显示一行提示，不占空间。
- 场景阅读入口：按生活场景生成/阅读短文。

### 学习
- **开始复习**：按间隔重复算法到期的卡片。
- **学新词**：按词频或随机从词库选词。
- **智能选词**：按每日目标一次性挑好当天的词。
- 复习时对每张卡打「忘记 / 模糊 / 认识 / 牢记」四档，系统据此安排下次出现时间。

### 词库
- 21,430 词，支持英文拼写搜索；点任意单词展开详情。
- 详情页含音标、中文释义、例句、记忆钩子和发音按钮。
- 顶部下拉可按词书筛选。

### 真题训练
- **68 套 CET-4 / CET-6 真题**，可计时、作答、判分并逐题看解析。
- 按官方 710 分制组织，含阅读、写作、翻译等题型，**不含听力音频**。
- 另有 AI 出卷，可按难度和题型生成练习。

### 写作 / 范文
- 按场景与难度生成范文，支持中英对照与整篇朗读。
- 内置范文样本，离线可读。

### AI 教练
- 划选任意句子或单词，让 AI 精讲语法、词汇和用法。
- 支持英语对话与自定义训练。
- 需要在「设置 → AI 引擎」里填自己的 API Key；**不填也不影响其他所有功能**。

### 语法 / 水平测试
- 语法速查与专项练习；水平测试用于给出起始词书与难度建议。

## 六、发音是怎么来的

优先级从高到低：

| 形态 | 发音链路 |
|---|---|
| **安卓 APK** | 端侧神经语音（Kokoro / Piper 音色，离线）→ 系统 TTS → 无声 |
| **网页完整版 / 单文件手机版** | 真人录音词库 → 在线词典发音 → 浏览器语音 |

安卓 App 里的整句朗读不依赖浏览器语音，所以比网页版稳定。任何时候都没有可用音色时，「设置 → 朗读 → 声音自检」会显示卡在哪一步。

首次点朗读若无声，先点一次「声音自检」，看它给出的具体原因。

## 七、离线与隐私

- 词库、例句、68 套真题都在包内；单文件手机版把 98 份数据内联进一个 HTML，断网也能查词和做真题。
- 学习记录保存在浏览器 IndexedDB 或 App 本地存储里，没有账号，也没有服务器上传。
- 清除浏览器数据 / 卸载 App 会删除学习记录，请谨慎操作。
- AI 功能由浏览器或 App 直接调用你配置的服务商，本项目不代理、不把 API Key 存到服务器。
- 应用默认不会向任何本地端口发送请求；只有你在设置里主动填写了本地语音服务地址，才会去探活。

## 八、常见问题

**Q：网页打开是空白 / 一直转圈？**
A：刷新一次；若仍不行，用 `mobile.html` 单文件版。它不依赖外部 JS 和数据文件。

**Q：手机上浏览器打开网页很慢？**
A：`mobile.html` 约 13MB，首次加载需要几秒；加载完可添加到主屏幕，之后走缓存。

**Q：点朗读没声音？**
A：网页版先确认系统有英语语音包；App 里打开「设置 → 声音自检」，看端侧引擎与系统语音两行各自的状态。

**Q：为什么真题没有听力？**
A：听力原声音频体积过大（1.7GB），未随包发布；题目与原文保留，可阅读和作答，但不播放音频。

**Q：AI 功能要付费吗？**
A：本项目不收费。AI 调用使用你自己的 API Key，费用按你的服务商计费。

**Q：换手机后学习记录还在吗？**
A：不会自动同步。目前没有云同步功能，请把它当作本地单机应用。换机前请在设置里导出数据备份。

**Q：网页版和 APK 的学习记录能互通吗？**
A：不能。两者各自独立存储，本地不互通。

**Q：三个版本的内容会同步更新吗？**
A：会。每次发布同时更新三种形态，网页版和单文件版刷新即得，APK 需下载新版本覆盖安装。
