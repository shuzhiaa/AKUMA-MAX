## 二、GitHub 小白怎么下载

### 下载安卓 APK

1. 打开 [Releases 页面](https://github.com/shuzhiaa/AKUMA-MAX/releases/latest)。
2. 找到最新版本号（例如 `v1.3.3`），展开下面的 **Assets**。
3. 点击 `AkumaMax-1.3.3-signed.apk` 开始下载。同名 `.txt` 是签名与安全自检说明，可看可不看。
4. 下载完成后按第三节安装。

如果浏览器提示“文件太大 / 不安全”，这是浏览器对 200MB 级 APK 的常见提示，选择“保留”即可。安装前请确认文件来自本仓库。

### 下载单文件手机版

1. 打开 [mobile.html](https://shuzhiaa.github.io/AKUMA-MAX/mobile.html)。
2. 在浏览器菜单里选“添加到主屏幕”或“保存网页”，之后离线也能打开。
3. 也可以在 GitHub 仓库文件列表里点 `mobile.html` → 右上角 `Raw` → 浏览器菜单“另存为”。

### 收藏与更新

- 点仓库右上角的 `Star`，以后能在 GitHub 个人主页快速找到。
- 网页版刷新页面就是最新版；APK 需要到 Releases 下载新版本覆盖安装（签名不变，学习记录会保留）。

## 三、安装安卓 APK

1. 把 APK 复制到手机，点击安装。
2. 系统提示“禁止安装未知来源应用”时，按提示给文件管理器或浏览器一次安装权限，装完可以关掉。
3. 首次启动会导入词库与真题，约 10–20 秒，请等首页出现再操作。
4. 应用约 200MB，需要留出足够的存储空间。

支持 Android 8 及以上；安装包内包含 arm64 与 x86_64 兼容库。应用不申请网络、通讯录、定位等权限。

---

## 四、第一次使用：三步开始

1. **选水平**：首页按提示做一次水平测试，或直接选 N5–N1 / 四级 / 六级。以后可在“设置”里改。
2. **定目标**：在“设置 → 每日目标”决定每天学几个新词、复习多少张卡。
3. **开始复习**：回到“今日”页，点“开始复习”；如果是第一次使用，先去“学习”页学几个新词。

之后每天只要打开“今日”页，按提示复习即可。数据保存在本机浏览器或 App 内，不需要登录。

## 五、功能导览

### 今日
- 待复习数量、今日新词进度、连续学习天数。
- 近 14 天学习曲线；没有记录时只显示一行提示，不占空间。
- 场景阅读入口：按生活场景快速生成/阅读短文。

### 学习
- **开始复习**：按间隔重复算法到期的卡片。
- **学新词**：按词频或随机从词库选词。
- **智能选词**：按每日目标一次性挑好当天的词。
- 复习时对每张卡选择“忘记 / 模糊 / 认识 / 牢记”，系统据此安排下次出现时间。

### 词库
- 21,430 词，支持英文拼写搜索；点任意单词可展开详情。
- 详情页包含音标、中文释义、例句、记忆钩子和发音按钮。

### 真题训练
- 69 套 CET-4 / CET-6 真题，可计时、作答、判分并逐题查看解析。
- 按官方 710 分制组织，含阅读、写作、翻译等题型，**不含听力音频**。
- 另有 AI 出卷，可按难度和题型生成练习。

### 写作 / 范文
- 按场景与难度生成范文，支持中英对照与整篇朗读。
- 内置范文样本，离线可读。

### AI 教练
- 划选任意句子或单词，让 AI 精讲语法、词汇和用法。
- 支持英语对话与自定义训练。
- 需要在“设置 → AI 引擎”里填自己的 API Key；不填也能用其他所有功能。

### 语法 / 水平测试
- 语法速查与专项练习；水平测试用于给出起始词库与难度建议。

## 六、发音是怎么来的

优先级从高到低：

1. **安卓 App**：内置离线神经语音（Kokoro / Piper 英文音色），没有网络也能朗读；再往下是系统 TTS。
2. **网页版**：真人录音词库 → 在线词典发音 → 浏览器语音。
3. 任何时候都没有可用音色时，“设置 → 朗读 → 声音自检”会显示卡在哪一步。

手机 App 里的整句朗读不依赖浏览器语音，所以比网页版稳定。首次点朗读若无声，先点一次“声音自检”。

## 七、离线与隐私

- 词库、例句、69 套真题都在包内；网页版的 `mobile.html` 把 72 份数据内联进一个文件，断网也能查词和做真题。
- 学习记录保存在浏览器 IndexedDB 或 App 本地存储里，没有账号，也没有服务器上传。
- 清除浏览器数据 / 卸载 App 会删除学习记录，请谨慎操作。
- AI 功能由浏览器或 App 直接调用你配置的服务商，本项目不代理、不保存 API Key 到服务器。

## 八、常见问题

**Q：网页打开是空白 / 一直转圈？**
A：刷新一次；若仍不行，用 `mobile.html` 单文件版。它不依赖外部 JS 和数据文件。

**Q：手机上浏览器打开网页很慢？**
A：`mobile.html` 约 12MB，首次加载需要几秒；加载完可添加到主屏幕，之后走缓存。

**Q：点朗读没声音？**
A：网页版先确认系统有英语语音包；App 里打开“设置 → 声音自检”，看端侧引擎与系统语音两行各自的状态。

**Q：为什么真题没有听力？**
A：听力原声音频体积过大，未随包发布；题目与原文保留，可阅读和作答，但不播放音频。

**Q：AI 功能要付费吗？**
A：本项目不收费。AI 调用使用你自己的 API Key，费用按你的服务商计费。

**Q：换手机后学习记录还在吗？**
A：不会自动同步。目前没有云同步功能，请把这当作本地单机应用。
